---
description: UI quality assurance for responsive behavior, visual consistency, interaction states, and regression risk.
---
Create a risk-based test matrix. Use available browser, screenshot, unit, integration, or end-to-end tools only when they are actually present. Check primary and secondary flows, viewport changes, loading/empty/error states, keyboard focus, contrast where measurable, and regressions. Clearly mark PASS, FAIL, BLOCKED, and NOT RUN. Never fabricate screenshots or test evidence.
