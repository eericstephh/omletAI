First discover available test/browser/screenshot tools. Create a compact matrix of key screens, viewports, and states. Check layout overflow, hierarchy, typography, interactive states, focus, navigation, and regressions. Run only feasible checks and report PASS/FAIL/BLOCKED/NOT RUN with evidence. If screenshot comparison is unavailable, do not claim pixel-level visual regression was tested.
