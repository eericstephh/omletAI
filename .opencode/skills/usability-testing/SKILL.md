# Usability test planning

## When to use
Use when validating whether users can complete a task with the proposed design.

## Workflow
1. Define the decision the test should inform and the target user/task.
2. Write realistic, neutral scenarios without revealing the intended path.
3. Define success, errors, time/effort indicators, and observation notes.
4. Run the smallest appropriate study and state limitations honestly.
5. Summarize patterns, severity, and next design changes without overgeneralizing small samples.

## Expected outputs
- Test script
- Task success criteria
- Observation template
- Synthesis and next steps

## Avoid
- Leading participants to the answer
- Treating a small qualitative sample as statistically representative

## Done when
- The recommendations connect to the actual product goal and user task.
- Important assumptions and unverified claims are explicitly labeled.
- The result is specific enough to implement or evaluate.
