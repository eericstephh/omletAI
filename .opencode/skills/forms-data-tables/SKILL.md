# Enterprise forms and data tables

## When to use
Use for admin and operational interfaces with high data density.

## Workflow
1. Choose table columns based on common decisions and actions.
2. Support sorting, filtering, pagination/virtualization, row selection, and bulk action feedback as needed.
3. Keep column labels, units, status meanings, and empty/loading/error states consistent.
4. Make row actions discoverable without clutter and protect destructive bulk operations.
5. Test long values, many rows, narrow viewports, and keyboard navigation.

## Expected outputs
- Table behavior spec
- Column priority
- Bulk-action states
- Density and accessibility checks

## Avoid
- Putting every available field in the default view
- Ambiguous bulk selection scope
