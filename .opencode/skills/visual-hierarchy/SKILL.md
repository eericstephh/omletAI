# Visual hierarchy and composition

## When to use
Use for screen design, redesign, and visual critique.

## Workflow
1. Establish one dominant task or message per screen where appropriate.
2. Use scale, placement, contrast, whitespace, grouping, and alignment to signal priority.
3. Make related items look related and unrelated items visually distinct.
4. Control competing focal points; use emphasis sparingly and consistently.
5. Review the screen at a glance, at normal reading size, and with dense/long content.

## Expected outputs
- Hierarchy map
- Composition decisions
- Priority corrections
- Review checklist

## Avoid
- Making every card or button equally prominent
- Using decoration as a substitute for hierarchy

## Done when
- The recommendations connect to the actual product goal and user task.
- Important assumptions and unverified claims are explicitly labeled.
- The result is specific enough to implement or evaluate.
