# Data visualization design

## When to use
Use when presenting quantitative or categorical information.

## Workflow
1. Identify the analytical question and data type before selecting a chart.
2. Use honest scales, clear labels, units, legends, and meaningful comparison baselines.
3. Use color consistently and avoid relying on color alone.
4. Provide accessible summaries or tables for important chart information.
5. Account for missing data, uncertainty, outliers, and small-screen readability.

## Expected outputs
- Chart recommendation and rationale
- Label/unit rules
- Accessibility fallback
- Misinterpretation risks

## Avoid
- 3D effects or decorative chart junk
- Truncated axes or unlabeled metrics that mislead

## Done when
- The recommendations connect to the actual product goal and user task.
- Important assumptions and unverified claims are explicitly labeled.
- The result is specific enough to implement or evaluate.
