# Dashboards and data-dense interfaces

## When to use
Use for admin panels, analytics, monitoring, and operational tools.

## Workflow
1. Start with the decisions users need to make and the data needed for those decisions.
2. Establish priority metrics, comparison context, time range, and clear units.
3. Choose visualizations that fit the data and avoid misleading scales.
4. Support filtering, sorting, drill-down, loading, no-data, stale-data, and error states.
5. Balance scanability with information density; do not turn every metric into a card.

## Expected outputs
- Dashboard hierarchy
- Metric definitions
- Visualization choices
- Filter and state behavior

## Avoid
- Charts without units or context
- Using visualizations that distort comparisons

## Done when
- The recommendations connect to the actual product goal and user task.
- Important assumptions and unverified claims are explicitly labeled.
- The result is specific enough to implement or evaluate.
