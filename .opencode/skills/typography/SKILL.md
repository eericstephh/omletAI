# Typography systems and readable type

## When to use
Use when choosing fonts, type scales, line lengths, or text hierarchy.

## Workflow
1. Choose typefaces for language coverage, legibility, product character, and available licensing.
2. Define semantic text roles and a consistent scale rather than arbitrary per-element sizes.
3. Set line height, measure, weight, and paragraph spacing for the actual content and viewport.
4. Check numeric data, punctuation, long headings, localization, and font-loading fallback.
5. Preserve hierarchy without relying on tiny text or low contrast.

## Expected outputs
- Type scale and roles
- Usage guidance
- Responsive type rules
- Font and localization risks

## Avoid
- Too many unrelated font sizes
- Long lines, compressed line-height, or fake bold styles

## Done when
- The recommendations connect to the actual product goal and user task.
- Important assumptions and unverified claims are explicitly labeled.
- The result is specific enough to implement or evaluate.
