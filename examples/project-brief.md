# Example Project Brief

- **Product:** Subscription-based video editing app
- **Platform:** Android phone, portrait-first
- **Primary user:** Creator who wants to edit a short video quickly
- **Core task:** Import clip, add readable subtitles, preview, export
- **Success outcome:** User can complete the edit without confusing timeline gestures or losing work
- **Constraints:** Existing codebase and dependencies should be preserved unless change is justified
- **Design direction:** Professional, clear, modern, high contrast; avoid decorative clutter
- **Important states:** No imported media, model download, processing, transcription failure, export progress, export failure, completed export
- **Acceptance criteria:** Preview and timeline stay synchronized; actions have clear feedback; primary controls are discoverable; Persian text and RTL behavior are correct; critical flows are verified on available tooling
