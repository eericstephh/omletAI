# Game UI and HUD design

## When to use
Use for game menus, HUDs, inventories, maps, settings, and progression interfaces.

## Workflow
1. Prioritize moment-to-moment play: HUD elements should be readable without stealing attention.
2. Separate critical gameplay feedback from persistent status and optional information.
3. Support safe areas, multiple aspect ratios, controller/keyboard/touch input, and remapping where relevant.
4. Use clear feedback for damage, cooldowns, rewards, progression, and unavailable actions.
5. Keep typography and iconography readable during motion and under varied backgrounds; test accessibility options.

## Expected outputs
- HUD hierarchy
- Input/state matrix
- Aspect-ratio rules
- Feedback and readability checks

## Avoid
- Overloaded HUDs
- Tiny text or color-only status indicators

## Done when
- The recommendations connect to the actual product goal and user task.
- Important assumptions and unverified claims are explicitly labeled.
- The result is specific enough to implement or evaluate.
