# Iconography, illustration, and imagery

## When to use
Use when choosing or creating visual assets for interface communication.

## Workflow
1. Prefer consistent icon families and clear semantic meaning.
2. Use text labels for unfamiliar or high-impact actions; provide accessible names.
3. Choose imagery that supports the product narrative and content rather than generic decoration.
4. Define crop, aspect ratio, responsive behavior, loading, and fallback treatment.
5. Respect licensing, brand constraints, and privacy in user-generated imagery.

## Expected outputs
- Icon/asset direction
- Usage rules
- Fallback behavior
- Asset sourcing constraints

## Avoid
- Mixing inconsistent icon styles
- Using decorative images that compete with primary content

## Done when
- The recommendations connect to the actual product goal and user task.
- Important assumptions and unverified claims are explicitly labeled.
- The result is specific enough to implement or evaluate.
