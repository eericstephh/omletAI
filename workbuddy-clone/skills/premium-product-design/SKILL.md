# Premium Product Design

## Workflow
1. Establish audience, product personality, use context, and the main job the screen supports.
2. Pick a coherent visual direction: density, geometry, type character, color temperature, imagery, and motion.
3. Define a small number of memorable visual decisions and apply them consistently.
4. Balance brand expression with task clarity, readability, performance, and accessibility.
5. Review the interface at normal size and with real content; remove effects that do not improve meaning.

## Quality bar
- Strong hierarchy, intentional spacing, refined details, and clear interaction states.
- Visual distinction comes from composition, typography, and product-specific choices—not a pile of gradients.
- The UI still works when animations, imagery, or optional decoration are unavailable.
