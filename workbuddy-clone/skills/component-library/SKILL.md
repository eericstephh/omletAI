> **WorkBuddy note:** این اسکیل از «commands» سیستم OpenCode تبدیل شده است؛ آن را مثل یک دستورالعمل اجرا کنید.

Inventory repeated UI patterns before adding components. Identify shared primitives, compound components, variants, and one-off product-specific elements. Define token usage, accessibility contracts, state behavior, and examples. Implement only high-value components supported by current screens. Avoid speculative abstraction and avoid creating a second design system beside the existing one.
