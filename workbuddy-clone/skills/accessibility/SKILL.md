# Accessibility

Use the detailed `accessibility` skill in the catalog for full workflow.

## Core rules
- Prefer semantic elements and native controls.
- Support keyboard operation, visible focus, meaningful names, and sensible focus order.
- Check contrast, zoom/reflow, non-color cues, target sizes, and reduced motion.
- Automated tools help but do not prove complete accessibility.
