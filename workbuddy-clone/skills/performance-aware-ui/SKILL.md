# Performance-aware UI design

## When to use
Use when designing image-heavy, animated, or data-rich interfaces.

## Workflow
1. Identify perceived and measured performance risks: layout shifts, blocking work, large assets, excessive rendering, and long feedback delays.
2. Use appropriate image sizes, lazy loading, stable dimensions, and progressive disclosure.
3. Keep motion purposeful and account for lower-powered devices.
4. Design skeletons and progress indicators only when they improve understanding.
5. Use available profiling tools and distinguish measured results from design hypotheses.

## Expected outputs
- Performance risk list
- Asset/loading strategy
- Perceived feedback plan
- Measurement plan

## Avoid
- Invented performance improvements
- Loading effects that increase work without adding clarity

## Done when
- The recommendations connect to the actual product goal and user task.
- Important assumptions and unverified claims are explicitly labeled.
- The result is specific enough to implement or evaluate.
