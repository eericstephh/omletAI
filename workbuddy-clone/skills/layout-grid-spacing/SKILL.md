# Layout grids and spacing

## When to use
Use for consistent page geometry and component rhythm.

## Workflow
1. Choose a spacing scale appropriate to the product density and platform.
2. Set container widths, page gutters, column behavior, alignment rules, and breakpoints.
3. Use whitespace to group and separate content intentionally.
4. Check nested spacing for cumulative bloat and dense data layouts for wasted space.
5. Validate the grid with real content lengths and responsive reflow.

## Expected outputs
- Grid/container rules
- Spacing tokens
- Density guidance
- Responsive behavior

## Avoid
- Arbitrary one-off margins everywhere
- Rigid grids that break under translation or zoom

## Done when
- The recommendations connect to the actual product goal and user task.
- Important assumptions and unverified claims are explicitly labeled.
- The result is specific enough to implement or evaluate.
