# UX writing and content design

## When to use
Use when writing labels, instructions, errors, onboarding, and help text.

## Workflow
1. Lead with the user's task and use concrete, familiar words.
2. Keep labels specific and consistent across the product.
3. Make error messages explain the issue and the next action.
4. Use tone appropriate to context; be calm and direct in high-stress or destructive flows.
5. Check truncation, translation expansion, date/number formats, and right-to-left rendering where relevant.

## Expected outputs
- Content principles
- Key interface copy
- Terminology list
- Edge-state messages

## Avoid
- Vague labels like 'Continue' when the action is unclear
- Blaming users or hiding consequences

## Done when
- The recommendations connect to the actual product goal and user task.
- Important assumptions and unverified claims are explicitly labeled.
- The result is specific enough to implement or evaluate.
