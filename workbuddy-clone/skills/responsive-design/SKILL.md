# Responsive Design

Use the detailed `responsive-design` skill in the catalog for responsive layout work. This legacy entry remains for compatibility with the initial kit.

## Core rules
- Design reflow rules rather than merely scaling a desktop screenshot.
- Protect primary actions and meaningful content on narrow screens.
- Check long text, zoom, orientation, touch input, and overflow.
- Report which viewports were actually tested.
