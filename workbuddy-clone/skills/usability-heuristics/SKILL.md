# Usability heuristics review

## When to use
Use for expert evaluation of an existing screen or flow.

## Workflow
1. Check visibility of system status, real-world match, user control, consistency, error prevention, recognition, efficiency, minimalism, recovery, and help.
2. Record concrete observations with the screen and interaction where they occur.
3. Rate severity by impact, frequency, and recoverability—not personal taste.
4. Offer the smallest fix that addresses the root cause.
5. Mark findings as observed, inferred, or needing user validation.

## Expected outputs
- Prioritized heuristic findings
- Severity and rationale
- Specific fixes
- Validation suggestions

## Avoid
- A score with no evidence
- Calling a stylistic preference a usability violation

## Done when
- The recommendations connect to the actual product goal and user task.
- Important assumptions and unverified claims are explicitly labeled.
- The result is specific enough to implement or evaluate.
