# Wireframing and structural layout

## When to use
Use before detailed visual styling when structure is uncertain.

## Workflow
1. Start from content, user priority, and task order rather than decoration.
2. Define regions, hierarchy, content density, primary action, and responsive reflow.
3. Use low-fidelity structure to compare meaningful alternatives.
4. Check long content, empty data, and secondary actions—not just ideal sample content.
5. Lock the structure only after key task and hierarchy questions are resolved.

## Expected outputs
- Screen structure
- Layout rationale
- Alternative tradeoffs
- Open questions

## Avoid
- High-fidelity polish before hierarchy is settled
- Using placeholder content that hides real layout constraints

## Done when
- The recommendations connect to the actual product goal and user task.
- Important assumptions and unverified claims are explicitly labeled.
- The result is specific enough to implement or evaluate.
