> **WorkBuddy note:** این اسکیل از «commands» سیستم OpenCode تبدیل شده است؛ آن را مثل یک دستورالعمل اجرا کنید.

Audit the current interface and code before editing. Identify the highest-impact UX and visual issues; separate usability problems from aesthetic preferences. Preserve routes, content, and working interactions unless change is justified. Propose a prioritized plan, select relevant skills, then implement the smallest coherent set of changes. Verify existing critical flows and responsive layouts with available tools. Report regressions, unverified areas, and tradeoffs.
