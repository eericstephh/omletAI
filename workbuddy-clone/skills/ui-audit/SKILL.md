Inspect the app and repository. Audit task clarity, navigation, content hierarchy, visual rhythm, forms, feedback states, responsive behavior, keyboard use, semantic structure, contrast risks, and design consistency. Use relevant skills from the catalog. Return findings ordered by severity with: location, evidence, user impact, recommended fix, effort, and confidence. Distinguish observed facts from hypotheses. Do not change code unless asked.
