# Release Checklist

- [ ] README and skill catalog match the files in the repository.
- [ ] Agent and command frontmatter is compatible with the target OpenCode version.
- [ ] Skills have a clear scope and do not merely duplicate other skills.
- [ ] Example task has been run in OpenCode with the target model/provider.
- [ ] Existing project behavior is preserved in an implementation test.
- [ ] Lint, typecheck, tests, and build are run when applicable.
- [ ] Browser/device checks are reported honestly.
- [ ] No secrets, private data, or generated user artifacts are included.
- [ ] Archive and repository file paths are checked before release.
