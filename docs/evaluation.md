# Evaluation Rubric

Score each dimension from 1 (poor) to 5 (excellent), and cite evidence for each score.

- User/task clarity
- Information hierarchy
- Navigation and findability
- Visual consistency and craft
- Interaction feedback and recovery
- Responsive behavior
- Accessibility foundations
- Content clarity
- Reusability and maintainability
- Verification quality

A high visual score cannot compensate for broken task completion or inaccessible controls. Record critical blockers separately; do not average them away.
