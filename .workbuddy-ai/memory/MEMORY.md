## Highest-value traps

- **A missing import is the #1 cascade cause** — add it, recompile, *then* diagnose. `private const val` cannot
  sit between imports; a literal `*/` inside a KDoc silently ends the comment.
- **A wrong KDoc teaches the wrong invariant** — verify by grepping the **consumers**.
- **A forwarded-only parameter eventually stops being forwarded** (fade on `StemClip`, `motionTrack` in
  `RoomProjectRepository`, `voiceEffect` in `AudioMixerPlayer`'s key list). New per-clip field → grep every
  construction site *and* every cache-key list.
- **Tests: JUnit4 + coroutines-test + org.json only.** Hilt VMs can't be built in JVM → pure top-level fn in
  `model/`, or a **source-shape test**. ⚠️ A ONE-LINE `/** … */` makes a line-oriented stripper swallow to the
  next `*/`; the copies in `CustomFontWiringTest`, `SubtitleEditingWorkflowTest`, `ProgressBarWiringTest`,
  `NativeEngineFailureWiringTest`, `OverlayMaskWiringTest`, `AudioLaneLifecycleWiringTest` must agree. On
  failure **grep the RAW file** first.
- ⚠️ **Stale closures in long-lived `DisposableEffect`s** are the most-repeated bug class (a 33 ms poller read
  a captured `isPlaying` and hard-paused playback). Read via `rememberUpdatedState(...).value`; a state the
  effect must *write* needs `var x by remember { mutableStateOf(...) }`.
- ⚠️ **Media3 audio lanes are 16-bit, always** — `SonicAudioProcessor.configure` throws on non-`PCM_16BIT` and
  converters sit at the pipeline **head only**. A `PCM_FLOAT` processor before a Sonic stage kills every play.
  `javap -c` the shipped class.
- ⚠️ **MediaPipe JNI**: `tasks-vision` ships no `.so`; the only lib is `tasks-core`'s
  `libmediapipe_tasks_jni.so`, shared by both engines via `ai/MediaPipeNativeLib.kt`.
- ⚠️ **`AiToolRegistry` resolves engines from the Hilt `List<AiToolEngine>`** in
  `AppModule.provideAiToolEngines`; adding an engine = adding it there. `SpectralGateVoiceClean` is
  intentionally unregistered.
- ⚠️ **`models.lock.json` exists twice** (`app/ai-models/` is truth; `assets/` regenerated by `preBuild`).
  `"bundled": false` = never packaged. `BundledAssetIntegrityTest` asserts they agree.
- ⚠️ **`unitTests.isReturnDefaultValues = true`** makes `android.*` inert (`Rect`/`Bundle` → `0`) — tests can
  pass for the wrong reason. Plain floats for geometry.
- ⚠️ **Adding a ctor dep to a `@HiltViewModel` breaks its JVM test** — grep `app/src/test` for `ViewModel(`
  first; use interface + `Default…` + `InMemory…` fake in `di/AppBindings.kt`.
- ⚠️ Confirm the composable holds `viewModel` before wiring `viewModel.*`; `…Content` functions are
  callback-driven. Never put a fixed-size child in a weighted Compose slot (`Modifier.weight` is a scope
  extension → private composables need a pass-through `modifier`).
- ⚠️ **Do NOT call `setVideoEffects` at construction** (killed playback). Colour goes to the `TextureView`
  layer paint, never a Compose draw modifier on the `AndroidView`. `RgbMatrix` = 4×4 column-major.
- Preview `ExoPlayer` holds one item → `pos` is **already clip-local**. `VideoClip.brightness` is a non-null
  `Float` → always wins over `uiState`.

## Preview/export parity (🎯 hard-won)

- **The DIRECTION of a reported asymmetry is evidence** — enumerate mechanisms that *can* produce it first;
  read a persistence fn **to its closing brace** before calling it broken.
- `TextOverlay.fontFamily` ↔ `overlay.subtitleStyle.fontFamily` must both be written
  (`updateSelectedTextFont`); mismatch shows **only in the export**.
- **Parity is safe only when STRUCTURAL** — one shared pure function feeding both renderers.
- Compose `PathFillType` has no inverse; `android.graphics.Path` has `INVERSE_EVEN_ODD`. Preview knockout needs
  `CompositingStrategy.Offscreen` + `BlendMode.DstOut`. A `remember` that can return `null` must be called
  unconditionally.

## AI media (sampling, decoder lifecycle, subtitles)

→ **`reference/ai-media-decode.md`** — the narrow doc. Read it before touching `ai/media/`, `ai/engines/`,
`ai/ocr/`, `ai/upscale/`, `ai/audio/`, `ai/subtitle/`.

Four rules that abort the process rather than throw (pinned by `AiFrameDecodeLifecycleTest`):

- **Never render an EOS output** — `releaseOutputBuffer(st, !eos)`. A rendered EOS buffer yields an `Image`
  with no gralloc buffer, and the lazy `planes[0]` then trips CheckJNI (`non-zero capacity for nullptr
  pointer`), which no `try/catch` can catch.
- **Convert → close the `Image` → then run the AI op.** `onFrame` suspends for seconds against a 3-slot
  reader; holding the `Image` lets the driver reclaim it.
- **`acquireNextImage()` blocks** (never returns null) — gate it on a `pendingImages` counter.
- **No GL call without a current EGL context** — `glGetString` on a worker thread is a SIGSEGV.

Also there: `SequentialFrameSampler` is mandatory for frame analysis (never `OPTION_CLOSEST_SYNC`), and the
seven Whisper defects behind the Persian accuracy work (`logprob_thold = -1.0` because the temperature ladder's
last rung is accepted unconditionally; natural-text primer; AA resampling; conditioning; window planning;
cross-window carry).

## Matting mask (2026-10-29)

- **The category mask is binary** — `cls == 0 → 0f else 1f`. There is no soft knee and never was. Partial
  alpha came only from the old EMA; soft edges are the composition-time feather (`MaskPostProcess`).
- **`ai/MattingTemporalFilter.kt`** = median of three + scene-cut reset at 0.35. **Do not add an EMA on
  top** — it turns the median's one-frame lag into a multi-frame fade; `MattingTemporalFilterTest` catches it.
- **`ANALYSIS_MAX_SIDE = 512`, not 320.** 320 gives a 16:9 short side of 180, *below* the model's 256
  input → the segmenter upscales. The test `analysis bound keeps the short side at the model input` pins it.


## Sub-panel sizing (2026-10-01)

`model/SubPanelHeight.kt` (`resolveHeightDp`, `kindFor`, `Kind`) — pure floats, JVM-testable. `availableDp` is
the **post-chrome** height from `BoxWithConstraints` inside `SubPanelRow`;
`(available × fraction).coerceIn(min,max).coerceAtMost(available − 180)` — the last clamp **wins**. COMPACT is
an allow-list of exactly 11 (`SubPanelHeightTest`); everything else → GALLERY. `SubPanelContent` needs
`uiState.copy(toolPanel = panel)` because it dispatches on `uiState.toolPanel`.
