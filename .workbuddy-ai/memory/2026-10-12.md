# 2026-10-12 — Local logging & diagnostics system

Implemented a centralized, privacy-conscious logging + diagnostics system for Omelet.
Export pipeline and Whisper engine were **not** modified behaviourally — only
instrumented via optional nullable sinks.

## New package `app/src/main/java/com/aicreatorstudio/app/logging/`

- `LogRecord.kt` — pure: `LogLevel` (DEBUG/INFO/WARN/ERROR + `rank`,
  `defaultMinimum(isDebugBuild)`, `isEnabled`), `LogRecord` data class.
  Also hosts `DiagnosticsSummary` (pure filter/summary for the Settings UI).
- `LogSanitizer.kt` — pure privacy gate. Order matters: **BEARER before
  KV_SECRET** (otherwise `Authorization: Bearer sk-…` leaks the token).
  Strips unix/windows paths → basename, file:///content:// → last segment,
  long hex/base64 blobs, `key=value` secrets, explicit registered secrets.
- `LogFormat.kt` — pure JSONL codec + rotation policy.
  ⚠️ **Generation semantics: LOWER generation = NEWER** (0 = active = newest).
  `filesToPrune` sorts ascending by generation; `shouldRotate(current, incoming, cap)`.
  Caps: 512 KB/file, 4 files, 2 MB total.
- `OmeletLogStore.kt` — `@Singleton` Android writer. `filesDir/logs/`, single
  writer coroutine on `Dispatchers.IO`, `Channel(1024, DROP_OLDEST)`,
  `synchronized` append/rotate/prune cascade, `writesDisabled` flag on any
  write failure. Only touches files starting with `omelet.log` inside `logs/`.
- `OmeletLog.kt` — `@Singleton` facade. `minLevel` = DEBUG (debug build) /
  WARN (release). Forwards to logcat (unchanged tag) + persists structured
  record. `registerSecret()`, `setVerboseForTesting()`.
- `LogReportBuilder.kt` — pure shareable-report assembly (header + counts +
  latest problem + events), with defence-in-depth re-sanitization.

## Instrumented

- `export/VideoExportEngine.kt` — `ExportDiagnostics` gained `attach(OmeletLog?)`,
  a `runId` correlation id, `validateOutput()`. Records: export_started,
  stage events, encoder+muxer config, finalization started, output validated,
  export_succeeded/failed/cancelled. **Logcat output unchanged**; tooling is
  observation-only so the 88% fix and terminal latch are untouched.
- `ai/WhisperDiagnostics.kt` — `attach()`, structured records for
  stage/nativeLoad/inference, plus new `inferenceConfig()`, `released()`,
  `memoryPressure()`. `WhisperEngine` calls inferenceConfig once/run,
  released on free, memoryPressure on inference failure.

## UI

- `ui/screens/settings/DiagnosticsSection.kt` — «گزارش‌های فنی»: counts,
  latest-error card, problems-only switch, scrollable monospace event list,
  share (with confirmation explaining what leaves the device) via
  `ACTION_SEND` text (project has no FileProvider), clear (with confirmation).
- `SettingsSection` in `SettingsScreen.kt` changed `private` → `internal`.
- `viewmodel/DiagnosticsViewModel.kt` — `@HiltViewModel(DiagnosticsViewModel(OmeletLogStore))`.

## Wiring

`AICreatorStudioApp.onCreate` injects `OmeletLog` and calls
`ExportDiagnostics.attach(...)` + `WhisperDiagnostics.attach(...)` before
`CrashReporter.install`.
